Complete Flow for Adding a New App
Step	Action
1	Create your Go app (listens on localhost port)
2	Build binary locally or on VPS
3	Copy to /opt/leeforest/apps/appname/appname
4	Add A record on Namecheap: appname.leeforest.dev → 66.29.133.233
5	Edit /opt/leeforest/config.json — add site entry with hostname, port, binary path
6	Restart gateway: sudo systemctl restart leeforest

config.json example
{
  "domain": "leeforest.dev",
  "static_root": "/opt/leeforest/www",
  "cert_cache": "/opt/leeforest/certs",
  "listen_https": ":443",
  "listen_http": ":80",
  "redirect_http": true,
  "sites": [
    {
      "hostname": "statusboard.leeforest.dev",
      "upstream_port": 8081,
      "binary_path": "/opt/leeforest/apps/statusboard/statusboard"
    }
  ],
  "api_routes": []
}
